Northwind Architects: a website concept for a architecture studio

An editorial website concept for a fictional architecture studio, with oversized type, a line drawing, a project index and a studio statement.

Northwind Architects is a fictional business. This is a concept project EastLineWebCo designed to show our range. It is not a client engagement, and no client results are claimed.

The brief

A studio site is a portfolio first. It should let the work and the typography do the talking and stay out of the way.

What visitors need

What kind of work the studio does, a way to browse projects, and how the studio thinks.

Design decisions

  • Black, white and one signal-orange accent to keep the focus on the work.
  • Oversized type and an outlined headline for a confident, editorial feel.
  • A line drawing as the hero visual, so the page does not depend on photography.
  • A project index that is easy to scan, and a short studio statement.

What we built

A project index, a line drawing and a studio statement, set in Syne and Work Sans. The concept is a single responsive page that works on phones, tablets and computers.

Why it suits a design studio or portfolio-led business

A studio site is a portfolio first. The layout puts the answer to the visitor's first question in front of them early, and keeps the next step, such as calling, booking or browsing, close at hand.
